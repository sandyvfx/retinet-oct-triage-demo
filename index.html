Client Demo Summary

What is working in this POC

  • Interactive static workflow and de-identified case queue.
  • Scan intake, native conversion, biomarker review, BYOM request/response, doctor review, report export, workspace, similarity, and audit panels.

What is mocked

  • Uploads, authentication, database writes, model inference, heatmap creation, and report signing.

What needs real client integration

  • Storage, identity, EHR/report feeds, native converter deployment, model endpoints, vector index, and export signing.

What remains out of scope

  • Diagnosis, final compliance certification, production model training, and regulated product claims.
