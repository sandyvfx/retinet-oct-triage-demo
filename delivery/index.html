What RetiNet AI Platform POC is

A model-agnostic retinal and glaucoma workflow platform POC for OCT scan intake, native OCT conversion, biomarker review, BYO-model integration, doctor review, reporting, privacy-ready operations, and backend AI team workflows.

This is not a medical diagnosis system and is not a regulated medical device.

Who it is for

  • Medical officer / diagnostic center
  • Doctor / reviewer
  • Backend ML / AI team

What the current demo proves

Client-facing workflow, de-identified review surfaces, BYOM connector contract, static sample exports, and publish-hardened public demo packaging.

What is mocked

  • No real upload backend
  • No real authentication
  • No real database writes
  • No model endpoint call
  • No report-signing backend

What remains production work

  • Secure storage and role-based access
  • Native conversion service deployment
  • Model endpoint integration
  • Vector index for similarity search
  • Security review and clinical validation workflow
