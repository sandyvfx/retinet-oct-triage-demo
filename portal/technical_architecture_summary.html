Technical Architecture Summary

This phase documents the production architecture boundary. No production backend is implemented in this phase.

frontend static POC layer

Current static HTML review hub and demo pages for client evaluation.

future backend API layer

Production API boundary for cases, scans, reviews, model tasks, and exports.

ingestion service

Secure upload and case intake service for de-identified scan workflows.

native OCT conversion worker

Worker for vendor file conversion into B-scan sequences and manifests.

model connector service

BYOM request/response service for model tasks and safe output validation.

evidence registry

Registry for model cards, evidence summaries, metrics, and version lineage.

vector/similarity store

KNN and hybrid search store for reviewer context only.

audit/event log

Hash-chained events for review, model, export, and access activity.

report generation service

Draft/export/sign-off workflow for doctor-reviewed reports.

role-based access layer

Role and permission boundary for reviewers, admins, and AI operators.

deployment boundary

Clear separation between static POC, future backend, storage, and model endpoints.

Deployment Boundary

The current deliverable is a static POC layer. Production work requires secure backend APIs, storage, role-based access, audit/event logging, model connector services, vector infrastructure, and validation workflows before operational deployment.
