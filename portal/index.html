Executive Overview

RetiNet AI is a platform-first POC for retinal/OCT workflow review support. It connects OCT scan intake, native OCT conversion, biomarkers, doctor review, BYOM model integration, model evidence, similarity search, SDK/CLI operations, and backend AI handoff.

Doctor review required. Not a medical diagnosis system. Not a regulated medical device. Experimental public-dataset evidence only where model metrics are shown.

Portal Boundary

  • Static documentation and dashboard package only.
  • No production backend is implemented in this phase.
  • No auth, database writes, model training, checkpoint loading, or inference.
  • No PHI or raw vendor files are exposed.
